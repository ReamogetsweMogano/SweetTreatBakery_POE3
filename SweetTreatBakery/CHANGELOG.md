# Changelog — Sweet Treat Bakery

All dates use YYYY-MM-DD. This file records changes made to the project.

## 2026-10-31 — POE 3 improvement draft
- Corrected invalid HTML markup and made navigation consistent across all pages.
- Added a meta description and a descriptive page title to each page.
- Added semantic page sections, a skip link and current-page navigation indication.
- Rebuilt the shared stylesheet with CSS Grid, Flexbox, responsive breakpoints, relative units, focus styles and hover/active states.
- Added product search and category filtering.
- Added a product-image lightbox with close-button and Escape-key support.
- Connected the home-page special button to a message update.
- Added required form fields and JavaScript validity checks for enquiry and contact forms.
- Forms prepare an email draft using the visitor's email application; they do not send messages automatically and do not use AJAX or a server-side mail service.
- Added this changelog, a human-readable sitemap, an XML sitemap template and robots.txt.
- Added README guidance, testing steps and Harvard-style technical references.
